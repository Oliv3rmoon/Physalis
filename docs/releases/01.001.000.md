**Nightshade TV v1.001.000: the first Nightshade TV, based on ProsperoTV 01.000.090.** Nightshade TV is Oliv3rmoon's release of ProsperoTV by BlackBearReloaded: ProsperoTV 01.000.090 with a new name, Nightshade's look and updates from this repository.

## What changed

- **The name.** The PS5 home screen, the header, the opening, the About page, the update dialog, the notifications and every message say Nightshade TV, in all nine languages, and so does the phone remote's page.
- **The look.** Nightshade's black and red: near-black pages, black glass panels, a red accent for the main actions and the focus, and a near-black sky with a low red glow. The theme is called Nightshade in Settings; Ocean and Forest are still there.
- **The art.** The nightshade flower as the mark, and a new icon, home background and launch picture, drawn in Nightshade's style.
- **Updates from this repository.** The app asks [Oliv3rmoon/Nightshade-TV](https://github.com/Oliv3rmoon/Nightshade-TV/releases) for a newer release that is not a pre-release and installs it with **Update now**, after checking `PPSA99003.zip` against `SHA256SUMS`. It never offers ProsperoTV's own releases.
- **What stays.** The title ID (PPSA99003) and `/data/prosperotv`, so it installs over ProsperoTV and keeps your sources, favorites, recent channels and settings. Everything else is ProsperoTV 01.000.090.

Built and checked by the host tests; not yet run on a console.

## Install

- `PPSA99003.zip`: close ProsperoTV, extract the ZIP and copy its `PPSA99003` folder over your current one (usually `/data/homebrew/PPSA99003`). ProsperoTV doesn't offer this release itself, so this one is copied by hand; from it on, **Update now** applies the next one.
- `SHA256SUMS`: the checksum of the download. `gh attestation verify PPSA99003.zip -R Oliv3rmoon/Nightshade-TV` checks that this repository's workflow built it.
- To go back, copy an official [ProsperoTV release](https://github.com/ThatGuyKalvin/ProsperoTV/releases) over it the same way.
